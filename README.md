# Portfólio | Kauã Reis

Portfólio e roadmap de estudos de 24 semanas rumo a Engenheiro de Software, com foco em Java Backend.

- `index.html`: página principal
- `roadmap.html` + `roadmap-data.js`: roadmap interativo (edite os dados em `roadmap-data.js`)
- `guias/`: guias de LeetCode, Notion e inglês

Site estático em HTML, CSS e JS puro, sem build. Para publicar na Vercel, importe o repositório e deixe o framework como "Other".
