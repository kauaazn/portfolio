# Inglês para Engenharia de Software

Inglês é parte do roadmap: toda semana tem uma tarefa `EN:` com checkbox.

## Rotina diária (30–40 min)
| Habilidade | O que fazer |
|---|---|
| Leitura | 1 artigo técnico ou doc oficial (Baeldung, docs do Spring) — 10 min |
| Escuta | 1 vídeo/podcast técnico com legenda em inglês — 10 min |
| Fala | Shadowing: repita 2–3 min de um vídeo; depois explique em voz alta o que aprendeu no dia |
| Escrita | Commits, README, PRs, comentários de code review e notas do Notion em inglês |
| Vocabulário | 5 palavras/dia no banco "Inglês" do Notion + Anki |

## Marcos
- **Semanas 1–8:** ler docs e explicar conceitos simples em voz alta.
- **Semanas 9–16:** README, OpenAPI e commits 100% em inglês.
- **Semanas 17–24:** mock interviews (LeetCode + system design + "Tell me about yourself") em inglês.

## Frases de entrevista
- *"Could you clarify the input constraints?"*
- *"I'd start with a brute-force approach, then optimize."*
- *"The trade-off here is between memory and speed."*
- *"In my internship at Meep, I worked on…"*

## Dica
Grave-se explicando uma solução do LeetCode a cada sábado e compare ao longo das semanas.
