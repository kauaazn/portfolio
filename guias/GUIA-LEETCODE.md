# Guia de LeetCode (para quem está começando)

## 1. Setup (10 min)
1. Crie conta em leetcode.com e escolha **Java** como linguagem no editor.
2. Abra a lista **NeetCode 150** (neetcode.io/roadmap) — ela é a ordem que o roadmap segue.
3. Filtre por *Easy* nas primeiras 6 semanas, depois *Medium*.

## 2. Como resolver 1 problema (método dos 20-20-20)
1. **20 min tentando sozinho.** Leia, escreva exemplos, diga em voz alta (em inglês!) o que o problema pede.
2. **Se travou: veja só a dica/ideia**, nunca o código. Tente de novo por mais 10 min.
3. **Veja a solução**, entenda, **feche e reescreva do zero** sem olhar.
4. **Registre no Notion** (ver `GUIA-NOTION.md`): padrão, Big O, o que errou.

## 3. Os padrões que importam (ordem do roadmap)
Arrays/Hashing → Two Pointers → Sliding Window → Stack → Binary Search → Linked List → Trees → Heap → Graphs (BFS/DFS) → Backtracking → DP 1D.
Aprenda **o padrão**, não o problema decorado.

## 4. Cadência
- **3–5 problemas/semana** (já estão listados em cada semana do roadmap com prefixo `LC:`).
- **Revisão espaçada:** refaça os que errou após 3 dias, 1 semana e 1 mês.
- Aos sábados: 1 problema cronometrado (30 min) simulando entrevista.

## 5. Checklist de entrevista (pense alto, em inglês)
1. Repeat the problem. 2. Ask clarifying questions. 3. Give a brute-force solution. 4. Optimize and state time/space complexity. 5. Code. 6. Test with examples and edge cases.

Frases úteis: *"My first idea is a brute force…"*, *"The time complexity is O(n) because…"*, *"Let me walk through an example."*

## 6. Erros comuns
- Ver a solução em 5 minutos. - Resolver sem registrar. - Pular os easy. - Estudar só LeetCode e esquecer projetos: o roadmap mistura os dois de propósito.
